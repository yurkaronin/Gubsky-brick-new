# Новый проект

## 📖 Памятка по командам сборщика

npm start	Запуск в режиме разработки	Основная команда для работы
npm run build	Сборка для разработки	Проверить сборку без запуска сервера
npm run build:prod	Сборка для продакшена	Подготовить финальную версию для деплоя
npm run clean	Очистка собранных файлов	Удалить все скомпилированные HTML файлы

## ⚠️ Команды для отладки

npm run build:continue	Сборка с продолжением при ошибках	Продолжает сборку других файлов если в одном есть ошибка
npm run build:prod:continue	Продакшен-сборка с продолжением при ошибках	Аналогично, но с минификацией

## 🛠️ Вспомогательные команды

    npm run watch	Только отслеживание изменений (без сервера)
    npm run dev	Алиас для npm start
    npm run test:build	Тестовая сборка (development) с сообщением об успехе
    npm run test:prod	Тестовая сборка (production) с сообщением об успехе

### Для ежедневной работы:

    npm start # Сборка + локальный сервер + автообновление

### Для проверки сборки:

    npm run build # Если есть ошибки - остановится
    npm run build:prod # То же, но с минификацией

### Если сборка падает из-за ошибки в одном файле:

    npm run build:continue  # Продолжит сборку остальных файлов

### Перед деплоем:

    npm run clean          # Очистить старые файлы
    npm run build:prod     # Собрать продакшен-версию

## 🔧 Особенности поведения

По умолчанию (рекомендуется):
Остановка при первой ошибке - сразу видите проблему

Детальные сообщения об ошибках - файл, строка, причина

Автоматический перезапуск при изменениях - в режиме разработки

При использовании :continue:
Продолжает сборку несмотря на ошибки

Полезно когда нужно собрать остальные файлы

Не подходит для финальной сборки

## ⚡ Быстрые советы

Ошибка синтаксиса? - Используйте build:continue чтобы продолжить работу

Не видите изменений? - Запустите clean и пересоберите

Для продакшена всегда используйте build:prod

Локальный сервер доступен по http://localhost:3000


## 🆘 Если что-то пошло не так

Консоль зависла? - Нажмите Ctrl+C несколько раз

Сервер не запускается? - Проверьте порт 3000

Шаблоны не компилируются? - Запустите build для детальных ошибок

Все сломалось? - Удалите node_modules и package-lock.json, затем npm install
